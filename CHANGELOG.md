# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Added

- Initial release with 12 scrapers
- Support for major e-commerce sites
- Excel/CSV input/output support
- Comprehensive error handling
- Documentation and examples

## [1.0.0] - 2025-01-16

### Added

- Arabi Mart scraper (`arabiMart.py`)
- Birdsland JO scraper (`birdsland_scraper.py`)
- Ferplast scraper (`ferplast_scraper.py`)
- Info Scraper (`InfoScraper.py`)
- Jo-Cell scraper (`jo_cell_scraper.py`)
- Laroy Group scraper (`layorGroup.py`)
- Linker utility (`linker.py`)
- Generic scraper (`scraperGoat.py`)
- Suppliers scraper (`suppliersScrappar.py`)
- Woolapet scraper (`woolapet_scraper.py`)
- Zepter JO scraper (`zepter_scraper.py`)
- Samsung ACI scraper (`samsungaci.py`)

### Features

- Selenium and Playwright browser automation
- Pandas data processing
- BeautifulSoup HTML parsing
- Progress tracking with tqdm
- Checkpoint saving functionality
- Headless and headful modes
- Rate limiting and delays
- Comprehensive error handling
- Excel and CSV support
- Command-line interface for all scrapers

### Technical

- Python 3.8+ compatibility
- Virtual environment setup
- Requirements management
- Cross-platform support (Windows, macOS, Linux)
- Browser driver management
- Memory optimization
- Timeout handling

### Documentation

- Comprehensive README
- Internal development guide
- Usage examples
- Sample data files
- Installation instructions
- Troubleshooting guide
